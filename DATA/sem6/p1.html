Project-1 (BTCS 603-18)

Course Details

Credits: 3

Hours per Week: L:0 T:0 P:6

Course Description

Project-1 is a practical course that allows students to apply their theoretical knowledge to real-world problems. Students work on software development projects either individually or in teams under faculty supervision.

Objectives

  • Apply software engineering concepts and practices in real project development
  • Gain hands-on experience in project planning, analysis, design and implementation
  • Learn to work effectively in teams (for group projects)
  • Develop technical documentation and presentation skills
  • Learn to manage project timelines and deliverables

Project Phases

  1. Project Definition and Planning
  2. Requirements Analysis and Specification
  3. System Design
  4. Implementation and Testing
  5. Documentation and Presentation

Evaluation Components

  • Internal: 60 marks
  • External: 40 marks
  • Total: 100 marks

Deliverables

  • Project Proposal
  • SRS Document
  • Design Document
  • Working Software/System
  • Test Documentation
  • User Manual
  • Final Project Report
  • Project Presentation
