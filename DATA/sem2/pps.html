Programming for Problem Solving (BTPS101-18)

Course Details

  • Credits: 3
  • Contact Hours: L:3, T:0, P:0

Course Objectives

This course introduces students to the fundamentals of programming with an emphasis on problem-solving using algorithms. Students will learn to write basic programs using C language, focusing on control structures, functions, arrays, and recursion.

Course Outcomes

  • CO1: Formulate algorithms for simple programming tasks.
  • CO2: Write, compile, and debug programs in C language.
  • CO3: Understand and apply control structures, loops, and functions in programming.
  • CO4: Use arrays, strings, and pointers in programs.
  • CO5: Apply recursion and file handling in C programming.

Detailed Syllabus

Unit 1: Introduction to Programming (4 lectures)

  • Components of a computer system (disks, memory, processor, operating system, compilers etc.)
  • Idea of Algorithm: steps to solve logical and numerical problems
  • Representation of Algorithm: Flowchart/Pseudocode with examples
  • From algorithms to programs; source code, variables and data types, memory locations, syntax and logical errors

Unit 2: Arithmetic and Control Flow (8 lectures)

  • Arithmetic expressions and precedence (2 lectures)
  • Conditional Branching and Loops (6 lectures)
  • Writing and evaluation of conditionals
  • Iteration and loops

Unit 3-4: Arrays and Basic Algorithms (12 lectures)

  • Arrays (1-D, 2-D), Character arrays and Strings (6 lectures)
  • Searching, Basic Sorting Algorithms (Bubble, Insertion and Selection)
  • Finding roots of equations
  • Notion of order of complexity

Unit 5-6: Functions and Recursion (9-10 lectures)

  • Functions (including built-in libraries)
  • Parameter passing, call by value
  • Passing arrays to functions
  • Recursion with example programs (Factorial, Fibonacci series, etc.)

Unit 7-9: Advanced Topics (10 lectures)

  • Structures and Array of Structures
  • Pointers - basics and usage
  • Self-referential structures and linked lists
  • File handling (if time permits)

Suggested Books

  • Programming in ANSI C by E. Balagurusamy
  • The C Programming Language by Brian W. Kernighan and Dennis M. Ritchie
  • Schaum's Outline of Programming with C by Byron Gottfried

Programming for Problem Solving Lab (BTPS102-18)

Course Details

  • Credits: 2
  • Contact Hours: L:0, T:0, P:4

Course Objectives

The lab component of this course provides hands-on programming practice to reinforce concepts learned in the theory course. Students will work on various programming assignments involving the use of arrays, loops, functions, and file handling in C.

Course Outcomes

  • CO1: Write and test C programs for basic computational problems.
  • CO2: Apply loops, conditionals, and functions in programs.
  • CO3: Handle arrays, strings, and pointers in programming tasks.
  • CO4: Write recursive programs and solve numerical problems using C.
  • CO5: Perform file handling operations in C.

Laboratory Assignments

  1. Problem solving using computers:
    Lab 1: Familiarization with programming environment
  2. Variable types and type conversions:
    Lab 2: Simple computational problems using arithmetic expressions
  3. Branching and logical expressions:
    Lab 3: Problems involving if-then-else structures
  4. Loops:
    Lab 4: Iterative problems e.g., sum of series
  5. 1D Arrays:
    Lab 5: Array manipulation, searching, sorting
  6. 2D arrays and Strings:
    Lab 6: Matrix problems, String operations
  7. Functions:
    Lab 7: Simple functions with call by value
  8. Numerical methods:
    Lab 8-9: Root finding, numerical differentiation, numerical integration
  9. Recursion:
    Lab 10: Recursive functions
  10. Advanced concepts:
    Lab 11: Pointers and structures
  11. File handling:
    Lab 12: File operations
